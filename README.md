# Ace Bank Lite 🏦

A Java-based Banking Web Application.

## Features
- Login / Signup
- Deposit / Withdraw / Transfer
- Loan Request System
- Email Notifications
- Transaction History

## Tech Stack
- Java (Servlet + JSP)
- MySQL
- Tailwind CSS
- Apache Tomcat

## Security
- Password hashing (BCrypt)
- Session management
- Sensitive data hidden using .gitignore
